# Data policy

This repository contains **code only**.

- No tester datalogs (STDF/ATDF), exports, reports or screenshots of real data.
- No company, customer, device, program, lot, tester-host or people names - in code, comments, tests or docs.
- Tests and demos use **synthetic** data generated by the project (see `demo/`), never real files.
- Customer-specific settings (e.g. which test identifies a physical part) are stored per user,
  outside the repo, and are never committed.

Enforced by `.gitignore` and the pre-commit check `tools/check_repo_clean.py`
(install with `tools/install_hooks.bat`; the private word list `.private_denylist.txt` stays local).
