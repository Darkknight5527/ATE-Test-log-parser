About profiles

A profile is a small JSON file that names the fuse read-back test, the blown-bit test names, the tests used to match parts, and how the stage (Room / Hot / Cold) is read from the file name.

Profiles live in %APPDATA%\ate_log_parser\profiles, never in the app or the public repo. See examples/example_profile.json.
